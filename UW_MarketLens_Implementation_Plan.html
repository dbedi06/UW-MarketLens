DYOP · Implementation Plan

UW MarketLens

AI-Powered Prediction Market Reliability Platform
University of Washington · Spring 2025 · 3-Week Build · Team of 3

This plan breaks the project into self-contained sections. Sections are designed so several can be built at the same time and so any team member can pick up any section — we rotate through parts to learn the whole stack rather than splitting into silos.

Working principle. Agree on the shared JSON schemas first (Section 0). After that, every section is built against mock data, so nobody is blocked waiting on a teammate. Real wiring happens at integration in Week 2.

CTop Risks to De-Risk First

RiskAction this week
Polymarket trade-level API access — whole feature set depends on it Verify the real endpoint, rate limits, and trade-history availability on Day 1. Define a minimum viable feature set if only CLOB data is available.
30-market labeling & tester recruiting — manual, calendar-bound Start labeling and recruiting in Week 1, not Week 3 — these can't be sped up by coding harder.
NewsAPI free tier (100 req/day) Cache article retrievals per market from the start; only re-query on state change.
